# Quỳnh Engineering (quynh.vn) - Modern B2B Redesign Demo

Phiên bản Demo website sản phẩm & dịch vụ kỹ thuật cho **Công ty Cổ phần Công nghệ Quỳnh (Quynh Engineering Corporation)** theo phong cách **Modern Light Industrial / Clean Engineering / Premium B2B**.

## 🚀 Công nghệ sử dụng
- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS 3.4**
- **Lucide React**
- **Be Vietnam Pro & Inter**

## 🛠 Hướng dẫn cài đặt & chạy dự án

### 1. Cài đặt dependencies:
```bash
pnpm install
# hoặc: npm install
```

### 2. Chạy môi trường Development:
```bash
pnpm dev
```

### 3. Build & Chạy bản Production:
```bash
pnpm build
pnpm preview
```
